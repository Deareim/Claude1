The simplest loop. The Order Agent can't find the order, and instead of guessing it goes back to the customer, asks for the order number, and searches again: follow the dashed blue arrows. The orange path is the stop rule: after three failed tries the agent stops and hands the case to a person. In the demo, pick loop 1 and use "My package never arrived". Type 1004 when asked, or flip the switch so the customer keeps giving a wrong number and watch the stop rule kick in.
