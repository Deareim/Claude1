Agentic ideaWhere you see it in the demo
GoalSolve the customer's complaint, start to finish
Hand-offsEach agent passes its facts to the next one (the demo pauses here)
ToolsThe Order Agent searches the shop's order database
LoopNo order found? The agent asks the customer, then searches again
Human in the loopAnything over €100 waits for a manager to approve or reject
Walk the diagram left to right. Each box is one small agent with one job, like a team of specialists. Triage reads the message and turns it into facts. The Order Agent uses a tool, the order database, and if it can't find the order it goes back and asks the customer: that's the loop. The Resolution Agent applies the shop policy and drafts the reply. Then a fixed safety rule, not the AI, decides whether a person must approve: anything over 100 euros goes to the manager.
