Real systems fail: a database times out, an API is busy. A script would crash. An agent waits a moment and tries again, waiting a little longer each time: 1 second, then 2. That's the dashed blue loop. If the system is still down after three tries, the stop rule hands the case to a person with an honest message instead of retrying forever. In the demo, pick loop 4 and set the switch to "fails once" or "fails twice" to see recovery, or "database is down" to hit the stop rule.
