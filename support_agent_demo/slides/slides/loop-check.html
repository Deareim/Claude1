This loop is about quality. Two agents work together: a Writer drafts the reply, a Reviewer checks it against a fixed checklist: does it use the customer's name, say what we'll do, state the right amount, stay polite, and keep it short? If anything fails, the notes go back to the writer for a rewrite: the dashed blue arrows. Three failed drafts trigger the stop rule and a person writes the reply. In the demo, pick loop 2 and set the switch to "first draft is weak" to see one rewrite, or "every draft is weak" to hit the stop rule.
