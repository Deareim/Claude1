Time flows down. Dashed = the loop, only when information is missing. Orange = the safety rule: big amounts wait for a person.

Read it top to bottom: this is the journey of one complaint. The customer types a message, the Triage Agent uses Claude to understand it, the Order Agent searches the database. If it can't find the order, it doesn't guess: it goes right, asks the customer, and loops back up to search again. That dashed loop is what makes it an agent rather than a script. Then the Resolution Agent decides. Before anything happens, a fixed rule checks the amount: over 100 euros, a manager approves or rejects; otherwise the answer goes straight back. In real use the whole trip takes seconds; the live demo pauses at each hand-off.
