Layer 1 is one agent on its own. It understands the task, reasons about it with the language model, takes an action, often through a tool, and checks the result. If the goal isn't met, it goes round again. In the demo, each agent card is one of these loops, and the layer strip lights up blue whenever an agent is thinking or acting.
